# 轻量级单文件工具集

本仓库用于维护可在纯内网或离线环境直接运行的浏览器小工具。所有工具以极致轻量、无需安装、便于复制分发为首要目标。

## 工程原则

1. **单文件交付**：每个工具的功能、样式和脚本必须内联在一个 HTML 文件中。
2. **零运行时依赖**：不得依赖 Node.js、构建工具、框架、CDN 或外部网络资源，浏览器直接打开即可使用。
3. **离线优先**：工具必须适用于纯内网和无网络环境，目标浏览器为 Chrome 125+。
4. **轻量实现**：优先使用原生 HTML、CSS 和 JavaScript，避免引入不必要的库、文件和抽象。
5. **JSON 持久化**：需要保存、迁移或备份的数据，统一通过 JSON 文件导入和导出；不得新增数据库或服务端依赖。浏览器 localStorage 仅可作为本机临时便利缓存，JSON 是可移植数据的标准格式。
6. **独立目录**：每个工具使用独立目录，工具之间不得产生运行时耦合。
7. **文档同步**：功能、数据结构或使用方式变化时，应同步更新对应目录的 `README.md` 和 `CONTEXT.md`。

## 目录说明

│   ├── task-matrix.json              # JSON 数据示例或备份
│   ├── README.md                     # 工具说明
│   └── CONTEXT.md                    # 历史上下文或会话总结
└── otherUtils/                       # 其他独立辅助工具
    ├── jsonUtil/                     # JSON 格式化、压缩、转义与反转义工具
    │   ├── json-formatter.html       # 单文件工具本体
    │   ├── README.md                 # 工具说明
    │   └── CONTEXT.md                # 开发上下文与版本记录
    ├── markdownUtil/                 # Markdown 编辑与实时预览工具
    │   ├── markdown-editor.html      # 单文件工具本体
    │   ├── README.md                 # 工具说明
    │   └── CONTEXT.md                # 开发上下文与版本记录
    ├── logUtil/                      # 文本日志与 Java 异常分析工具
    │   ├── log-analyzer.html         # 单文件工具本体
    │   ├── README.md                 # 工具说明
    │   └── CONTEXT.md                # 开发上下文与版本记录
    └── pswdUtil/                     # 地址门户
        └── password-manager.html     # 单文件工具，收藏 HTML 上传入口

## 工具说明

- **task-matrix**：二维任务优先级矩阵，支持任务卡片、拖拽、动态行列、主题切换及 JSON 导入导出。
- **otherUtils**：非核心但可独立使用的开发与办公辅助工具集合。
- **otherUtils/jsonUtil**：JSON 格式化工具，支持格式化、压缩、转义、反转义、容错提示及双向数据同步。
- **otherUtils/markdownUtil**：Markdown 编辑器与浏览器，支持文件拖放、实时预览、目录导航与源文复制。
- **otherUtils/logUtil**：离线日志分析器 V2，支持多文件原子批次、文本/JSONL 与 UTF-8/GBK/GB18030 解码、组合查询、Trace/上下文、Java 异常归组、聚类、会话书签及脱敏导出。
- **otherUtils/pswdUtil**：地址门户，用户自建的网址集合，支持文件夹矩阵、手动新增网页、卡片同列排序和跨文件夹拖拽，以及可选的账号密码登记。卡片密码默认隐藏，点小眼睛仅临时查看对应密码；重新渲染或全局遮罩后恢复隐藏，显隐不写入 JSON。编辑时明文回填已有密码，留空仍保留原值。上传旁的「批量修改」支持跨文件夹勾选、全选和取消全选，统一修改账号、密码或仅其中一项；未启用字段保留各自原值，启用字段须填写非空新值。确认后一次性更新所选记录并自动保存，不改变名称、网址和布局，不调用扩展或修改网站实际密码；选择状态不持久化，取消清理明文草稿，遮罩后可恢复续填。导入浏览器收藏 HTML 时按全局唯一名称同步网址，保留已有账号密码、文件夹和手工顺序；新名称追加，消失名称仅加删除线，重名歧义跳过并提示。待决策卡片点「编辑」再「保存」即确认保留，即使不改字段也清除此卡片及所属文件夹的删除线并自动保存；其他待决策卡片不变。取消编辑或校验失败不确认保留，后续收藏同步若仍缺失会再次标记。固定 220×174px 紧凑卡片，支持横向滚动、黑白主题、悬浮编辑和 ⊞ 隐私遮罩。直接用 Chrome / Edge 打开 `otherUtils/pswdUtil/password-manager.html`，首次操作授权保存目录后自动读写 `password-manager.json`；文件采用固定密钥可逆混淆，无主口令，不提供可靠的密码保密。IndexedDB 仅记住授权目录句柄，不缓存登记内容；JSON 导入导出用于完整备份恢复，遇到外部文件冲突不覆盖。可选加载 `otherUtils/pswdUtil/extension` 配套扩展，目标版本为内网 Chrome 125，所用 API 均在此版本支持，不要求升级到更高版本。开启「允许访问文件网址」并逐站授权后，仅本地 HTML 卡片「跳转」会临时传递单条账号密码，以门户登记值覆盖登录框已有内容，包括浏览器记住的账号密码，不自动提交。门户未登记账号时清空唯一可识别的账号框，不将浏览器的其他账号配上登记密码。先立即执行无凭据表单探测，不再等待图片等非关键资源加载完成；确认导航已提交并两次识别同一 documentId 后才填充。填写阶段等待 8 秒，并为晚出现的表单提供最多 600ms 的稳定确认宽限；文档切换仅有界重新探测一次，不长期监听。支持同源 HTTP / 脚本重定向、同源 iframe 和旧式 frameset，以及依赖 focus / blur / input / change 的常见登录表单。跨域或跨协议登录须在卡片编辑中登记可选「登录域」（粘贴最终登录页网址，保存时仅保留 origin），并在最终登录页单独授权；只向此显式目标域的绑定文档填充，中间跳转域不接收凭据。登录域保存在门户 JSON，旧 JSON 无此字段仍兼容，收藏同步、移动及批量修改均保留它。重复点击不替换在途请求；填充异常、注入受限、无返回和导航变化分别提示。不能绕过企业禁用扩展/脚本注入的策略、要求真实键盘事件的控件或原生安全密码组件；autocomplete=off 不等于禁止本次脚本填写。扩展 1.0.7 兼容登录表单误用 autocomplete=new-password：仅在局部表单有唯一账号框和明确中英文登录操作、且无注册／改密码证据时填入。支持旧式链接、脚本按钮、有鼠标指针或按钮角色的 div/span、图片按钮及 aria-label/title/alt 标题；仅将这些结构用于判断，绝不点击或提交。按钮在 form 或输入行外时最多扩展两层局部容器，不跨入 body、其他表单或其他账号密码区，不借用其他表单关联的按钮。普通忘记密码帮助链接不作为当前改密码操作；隐藏、禁用、普通文字、无标题图片或证据不足、多密码／账号歧义仍停止。检测另显示 new-password 标记、登录／改密码判断标志、局部操作控件及可见／标题匹配计数、是否扩展局部范围，不回传按钮标题、输入值或图片 URL。普通打开或刷新网站以及扩展弹窗均不会主动填充。扩展弹窗提供「检测登录框」：仅在已授权的当前登录网站读取结构，显示可写、只读、禁用密码框及同源／不可访问框架计数，不读取输入值、不触发焦点或输入事件、不提交、不保存检测结果。检测仅接受扩展自有弹窗请求且不携带凭据，结构识别通过不等于实际填充成功；失败站点需结合检测码和门户底部提示继续定位。扩展无存储 API、无凭据文件读取功能、无凭据缓存；浏览器仅记住用户授予的权限。为兼容已有数据和授权关联，产品显示名改为「地址门户」，原有目录、HTML/JSON 文件名和内部格式标识保持不变。

## 统一命名规范

- 工具目录和 HTML 主文件使用语义明确的英文名称；HTML 文件使用 `kebab-case`，例如 `json-formatter.html`。
- 每个工具的使用说明统一命名为 `README.md`。
- 每个工具的开发记录、版本历史、上下文、交接或会话总结统一命名为 `CONTEXT.md`，不得混用 `CHANGELOG.md`、`session-summary.md`、`context-summary.md` 等名称。
- 示例或持久化数据文件使用 JSON，名称应与工具主文件一致，例如 `task-matrix.json`。
- 临时命令或操作说明如确需保留，统一使用 `COMMANDS.md`；空文件不应提交。
- 系统生成文件（如 `.DS_Store`）不得纳入版本控制。

## 新增工具检查清单

新增工具时，至少提供 `<tool-name>.html` 和 `README.md`；涉及数据保存时提供 JSON 导入/导出；存在开发记录、版本历史或交接信息时统一使用 `CONTEXT.md`。提交前确认工具可离线打开、无外部请求、无控制台错误，并验证主要功能在 Chrome 125+ 可用。
